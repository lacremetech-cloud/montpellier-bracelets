# Petit Trèfle – bracelets à Montpellier

One-page boutique (sans paiement en ligne) : le client choisit ses bracelets (bleu / vert / rose, 7 € pièce), un jour et un créneau, puis un message WhatsApp pré-rédigé s'ouvre vers le +33 7 82 61 48 61.

- `index.html` : le site (aucune dépendance, juste ouvrir le fichier ou l'héberger).
- `img/` : photos des bracelets.
- Prix, numéro, créneaux, jours fermés, modèles : bloc `CONFIG` en bas de `index.html`.

Mise en ligne gratuite : GitHub Pages (Settings → Pages → branche + dossier racine), Netlify Drop ou Vercel.
